# Contributing

Thanks for the report or proposal.

## Source Of Truth

`AuroraOps` private repository is the only source of truth.
`auroraops-base` accepts Issues and PRs as suggestion channels only.
Accepted code changes land in the private repository first, then sync back through the export and release flow.

## What To Open

- Bug report: describe actual behavior, expected behavior, and affected public repo.
- Proposal: explain why this should belong in `auroraops-base`, `auroraops-services`, or `auroraops-ops`.
- PR: allowed for discussion and review context, but do not assume direct merge into the public main branch.

## Do Not Post

- Secrets, tokens, passwords, cookies, private keys
- Private inventory, host details, or internal topology
- Production-only values copied from private environments

Use `SECURITY.md` for sensitive disclosures.
