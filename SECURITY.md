# Security Policy

Do not report secrets, private host details, privilege-escalation paths, or reusable credentials in public Issues or PRs.

## Private Reporting

Report security issues through a private channel controlled by the maintainer.
Do not open a public GitHub Issue for active leaks or exploitable paths.

## Public Repo Scope

These repositories are exported public products, not the private source-of-truth repository.
If a report is accepted, the fix lands in private `AuroraOps` first, then re-exports to the public repo.
